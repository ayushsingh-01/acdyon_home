# Acdyon Home

Submission for Acdyon Technologies Frontend Challenge, Part 2: Premium Home Page.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The `main` branch includes a GitHub Pages workflow. After pushing, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The site will then deploy at `https://ayushsingh-01.github.io/acdyon_home/`.
