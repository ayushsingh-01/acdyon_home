# Decisions

## Track selected: Part 2 - Premium Home Page

I designed Acdyon as a believable workspace for thoughtful, cross-functional teams. The product premise is intentionally narrow: help people make room for the few things that deserve attention. That gave the page a concrete job - make a visitor want to try a calmer alternative to noisy project software - instead of asking it to sell every possible feature.

The visual direction is editorial and spatial rather than a familiar dark SaaS gradient. A soft mineral palette, high-contrast italic display type, and the orbit illustration turn the product promise into a visual system: work can be in motion without all of it being urgent. The dashboard is a functional miniature demo. Switching views updates the priority card, and the access CTA gives clear feedback. Those are deliberately the only interaction moments, so motion and state both communicate the product rather than decorate it.

Under the time limit, I chose a single polished route and static, in-browser interaction over authentication, a real backend, or a large marketing surface. With a week, I would validate the message with target users, add a real waitlist flow, test content variants, and build the dashboard data model so the focus views were driven by live team activity.

I used AI as a production partner for initial code structure, copy exploration, and CSS iteration. I personally chose the fictional product positioning, refined every visible phrase to avoid unsupported claims, built the interaction model, reviewed responsiveness, and verified the production build. The page contains no testimonials, customer logos, user counts, or performance claims because none can be substantiated.
